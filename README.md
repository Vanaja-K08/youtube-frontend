YouTube Clone — Frontend

A fully functional YouTube Clone frontend built using React.js.
This application allows users to browse videos, search, filter, watch videos, comment, and manage their channel


Features\

👤 Authentication
--------------------
User registration & login
JWT-based authentication
Conditional header UI (login button / user icon)

Home Page
-----------------

Responsive video grid
Category filter buttons
Search bar (filters videos by title)
Sidebar toggle menu


Video Player Page
------------------------------
Video playback
Title & description
Channel name (clickable)
Like / Dislike buttons
Comments CRUD
Add comment
Edit comment
Delete comment

Channel Page
-------------------------------
View channel info
View uploaded videos
Create video
Edit video
Delete video

Tech Stack
----------------------------
React.js (Vite)
React Router DOM
CSS / Flexbox / Grid
Fetch API
JWT Auth
LocalStorage
